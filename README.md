# NERRA Calendar Widget — NERRA Classic

Заново созданный Android-проект, версия 1.0. Android 12 и новее (API 31+).

## Оформление

Фон виджета полностью прозрачный: нет рамок, карточек, теней или скруглённой подложки. Компактная надпись NERRA, текущая дата и единый вертикальный прокручиваемый список. Сначала события на весь день, затем по времени. Заголовка «По времени» нет. Названия событий переносятся без ограничения числа строк.

Предварительная палитра: графит #272A2D, золото #B79A62, светлый текст #F1EEE7. Это не подтверждённые бренд-цвета. Цветные точки используют displayColor системного календаря (цвет события, а при его отсутствии — календаря). Для отдельных проектов создайте отдельные календари с нужными цветами.

Автоцвет ориентируется на системную светлую/тёмную тему, а не анализирует обои. Можно принудительно выбрать светлый или графитовый текст. Настройка общая для всех экземпляров виджета.

## Подключение календаря

1. Настройте Яндекс Календарь в DAVx5 по актуальной инструкции этих сервисов и включите синхронизацию календарей Android.
2. Убедитесь, что события появились в системном приложении календаря, а нужные календари включены для отображения.
3. Откройте NERRA Calendar и разрешите чтение календаря.
4. Нажмите «Добавить виджет» или выберите его в списке виджетов рабочего стола.

Приложение читает CalendarContract.Instances: учитывает повторения, исключения, многодневные события и видимые календари. События на весь день сопоставляются с текущей датой в UTC, события по времени — с локальными границами дня. События, начавшиеся ранее сегодня, отмечаются стрелкой ↤ рядом со временем начала.

NERRA не запрашивает пароль Яндекса, не пишет в календарь и не имеет разрешения на интернет. Синхронизацию выполняет DAVx5. Кнопка ↻ перечитывает системный календарь, но не запускает сетевую синхронизацию DAVx5. Автоматическое обновление запрашивается раз в 30 минут; Android может задерживать его, в том числе при экономии энергии. На смену даты/часового пояса также запрашивается обновление; мгновенное обновление в полночь не гарантируется.

Нажмите NERRA для настроек, дату — для открытия системного календаря, событие — для его просмотра. Отображение и внешние отступы на рабочем столе зависят также от лаунчера.

## Сборка APK на компьютере

Нужны JDK 17, Gradle 8.11.1, Android SDK Platform 35 и Build Tools 35.0.0. Android Gradle Plugin 8.9.2 загружается из Google Maven. Gradle Wrapper в архив не включён.

Откройте эту папку в Android Studio и установите предложенные SDK-компоненты. Для командной сборки настройте ANDROID_HOME и выполните из корня проекта:

```text
gradle :app:assembleDebug :app:lintDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Это debug-сборка для ручной установки, не подписанный релиз для магазина.

## Сборка без локального Android SDK

Загрузите содержимое этой папки в корень своего репозитория GitHub. Откройте Actions → Build Android APK → Run workflow. После успешного завершения скачайте артефакт NERRA-Calendar-APK и распакуйте APK. Процесс требует подключения к интернету для загрузки компонентов сборки.
